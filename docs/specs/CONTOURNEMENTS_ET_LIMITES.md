# Limites, conventions et opérations restantes

État de référence : main `2e9e30c`, relu le 24 octobre 2026. Ce fichier rend visibles les compromis pour la soutenance ; il n'autorise pas à modifier les règles métier ni à contourner un test. Les travaux sur les branches du 24 octobre ne sont pas encore livrés sur cette base.

| Sujet | Limite ou convention actuelle | Traitement et vérification |
| --- | --- | --- |
| Compte PostgreSQL local — AUD-009 | La RLS existe, mais le compte superutilisateur fourni la contourne. Les contrôles API restent actifs. | Configurer un compte applicatif limité distinct du compte migrations/seed ; preuve déjà acquise sous compte CI limité. [SPEC-09](SPEC-09-soumission-isolee.md), [fiche](../audit/solutions-to-audit/AUD-009-database-company-isolation.md#implementation). Ce fichier n'active pas cette configuration. |
| Secret d'authentification — AUD-010 | Secret encore écrit dans le code ; déplacement et rotation reportés. | Clarifier avec le professeur, puis sélectionner une réalisation. [Question et contexte](../audit/questions-professeur.md), [fiche](../audit/solutions-to-audit/AUD-010-authentication-secret.md). Ne pas publier sa valeur. |
| Inscription par domaine — AUD-019 | Le domaine email suffit à rejoindre l'entreprise ; aucune preuve de possession ni invitation. | Convention pédagogique conservée, pas une garantie d'identité professionnelle. [SPEC-05](SPEC-05-inscription-atomique.md), [fiche](../audit/solutions-to-audit/AUD-019-inscription-domaine.md). |
| Notes de démonstration — AUD-018 | La relance successive du seed répare la même note. Deux seeds parallèles ne sont pas garantis sans doublon. Une note de seed incomplete n'a pas de clé de demande pour la reprise UI. | Relancer le seed pour la préparation de démonstration ; ne pas assimiler ce script au circuit de soumission interactif. Les essais utilisent uniquement des services isolés. [SPEC-10](SPEC-10-seed-recuperable.md). |
| Droits et liens de reçu — G10 / AUD-006 | Une rétrogradation affecte les requêtes suivantes, pas une requête déjà engagée ni une URL signée déjà délivrée. | Durée de lien bornée ; pas de révocation instantanée ajoutée. [SPEC-06](SPEC-06-droits-actuels.md), [fiche G10](../audit/solutions-to-audit/G10-droits-role-actuel.md). |
| OCR — AUD-008 | Pool local de capacité 1 par processus, aucune FIFO : une demande occupée est refusée en 503. Le délai de 40 s concerne le traitement ; l'OCR ne prend pas les PDF. | Choix de simplicité, pas une capacité globale garantie pour plusieurs instances. Mesures sur machine de développement et fixtures limitées. [SPEC-03](SPEC-03-ocr-borne.md), [mesures](../audit/evidence/ocr-pool-20261019/README.md). |
| Volume des listes — AUD-022 | Aucune pagination ni cache sélectionnés. Le précédent index expérimental n'a pas démontré de gain HTTP. | Mesurer puis conserver seulement une optimisation simple et justifiée, ou documenter la conservation de l'existant. [SPEC-11](SPEC-11-mesures-listes.md). |
| Dépendances — AUD-023 | Qualification réalisée ; les alertes ne sont pas corrigées par le simple rapport. | Sélectionner et vérifier séparément toute mise à jour compatible. La CI signale SPEC-12 en revue humaine. [SPEC-12](SPEC-12-qualification-dependances.md). |
| Tests du professeur | Non fournis lors de la validation rapportée du 22 octobre. | 302 tests locaux réussis ne prouvent pas la réussite de cette suite externe ni une couverture de 100 % du code. [Guide de tests](../testing/README.md). |

Les rôles manager et RH ont des périmètres différents : les RH décident les notes des managers racines, pas toutes les notes de l'entreprise. Une note d'employé ne devient donc pas visible à RH par simple appartenance au même domaine. [Matrice des droits](../audit/02-permissions-et-transitions.md).
